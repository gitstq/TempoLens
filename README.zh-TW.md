## 🎉 專案介紹

**TempoLens** 是一個完全運行於瀏覽器中的節拍器與音樂練習工作室：打開網頁就能練琴，
不需要安裝任何軟體、不依賴任何網路請求、不追蹤任何使用者資料。全部音色由 Web Audio
即時合成，全部邏輯皆為獨立自研實作。

**解決的真實痛點：**

- 🎸 **線上節拍器依賴網路**——練琴時網路波動導致節拍中斷，TempoLens 首次開啟後永久可用；
- 🥁 **功能單一**——大多數節拍器只有「速度 + 拍號」，缺少複節奏、搖擺、速度階梯等進階訓練能力；
- 🔐 **隱私顧慮**——各類「雲端同步」練習工具要求註冊登入，練習資料完全暴露給第三方；
- 📦 **臃腫複雜**——動輒數 MB 的框架依賴，TempoLens 全部原始碼不到 200 KB，單檔案即可散佈。

**靈感來源與自研差異化：**
專案構思受 GitHub Trending 中「終端原生 / 單檔案工具 / 本地優先」趨勢啟發，針對音樂人
日常練習場景獨立自研：以 **Web Audio 預調度引擎**（提前 120ms 規劃點擊，告別
`setInterval` 抖动）為核心，疊加**複節奏模式、智慧 Tap Tempo、速度階梯、練習例程、
打卡熱力圖**等進階能力，並以完整的三語介面涵蓋中英文使用者。

**技術棧：** 原生 HTML + CSS + JavaScript（ES5 相容 UMD 模組），零執行期依賴；
Node.js（≥18.17）僅用於開發期的語法校驗、單元測試與單檔案打包。

## ✨ 核心特性

- ⏱️ **精準節拍引擎** —— Web Audio 預調度（look-ahead scheduling），音訊層按
  `AudioContext.currentTime` 精確觸發，不受頁面幀率影響；背景分頁被降頻時自動丟棄積壓；
- 🥁 **複節奏（Polyrhythm）模式** —— 支援 2:3、3:4、4:5 等任意雙聲部疊加，
  自動計算最小公倍循環長度，複合節奏訓練利器；
- 🎚️ **搖擺律動（Swing）** —— 0–100% 連續可調，滿值時反拍精確落在三連音位置（2/3 拍）；
- 🎯 **智慧 Tap Tempo** —— 帶中位數離群值拒絕與逾時重置的打拍測速，連打 4 次即可穩定測速；
- 📈 **速度階梯（Tempo Ladder）** —— 一鍵產生「從 60 到 120、每級 +5、每級 4 小節」的漸進訓練；
- 📋 **練習例程（Routine）** —— 多步驟順序播放，到時間自動切換速度/拍號/細分，支援
  匯入匯出 JSON 與本機儲存；
- 🔥 **練習統計** —— 工作階段小節數、時長、加權平均速度、連續打卡天數與 17 週練習熱力圖，
  資料只存在你自己的瀏覽器裡；
- 🎨 **三語介面** —— 简体中文 / 繁體中文 / English 完整翻譯，自動跟隨瀏覽器語言；
- 🌗 **深淺雙主題** —— 跟隨系統或手動切換，`prefers-reduced-motion` 友善；
- 🔗 **設定分享** —— 全部設定編碼進 URL 雜湊，一條連結即開即用；
- 📴 **完全離線** —— 首次載入後無任何網路請求，`file://` 直接開啟也能運作；
- 🧩 **零依賴零建置** —— 沒有 `node_modules`，沒有打包器，沒有 CDN，原始碼即文件。

## 🚀 快速開始

### 方式一：直接開啟（零安裝）

無需安裝任何東西——直接用瀏覽器開啟 `src/index.html` 即可使用
（雙擊檔案或拖入瀏覽器視窗均可，支援 `file://` 協定）。

### 方式二：本機開發伺服器（可選）

```bash
# 需求 Node.js >= 18.17（僅開發期使用，應用本身零依賴）
node scripts/serve.mjs --port 8080
# 開啟 http://localhost:8080/
```

### 方式三：單檔案攜帶版

```bash
node scripts/build.mjs        # 產出 dist/tempolens.html（約 130 KB）
```

`dist/tempolens.html` 是內嵌了全部樣式與腳本的**單檔案應用**，可随意拷貝、
寄送郵件、放進隨身碟，雙擊即可執行。

### 開發期校驗（全部零依賴）

```bash
npm run check     # 語法校驗：node --check 覆蓋全部原始碼
npm test          # 單元測試：node --test（核心引擎全覆蓋）
npm run build     # 單檔案打包
npm run smoke     # 冒煙測試：行程內啟動靜態伺服器驗證關鍵資源
npm run verify    # 一鍵執行以上四項
```

## 📖 詳細使用指南

### 🎛️ 基本演奏

| 操作 | 方式 |
|---|---|
| 開始 / 停止 | 點擊 **▶ 開始** 按鈕，或按 <kbd>空白鍵</kbd> |
| 調整速度 | 拖動速度滑桿、輸入數字，或 <kbd>↑</kbd>/<kbd>↓</kbd>（<kbd>Shift</kbd> ±10） |
| Tap 測速 | 點擊 **👋 打拍測速** 或按 <kbd>T</kbd>，跟隨音樂敲擊 4 次以上 |
| 快速靜音 | <kbd>M</kbd> |
| 切換細分 | <kbd>1</kbd>–<kbd>4</kbd> 對應四分/八分/三連音/十六分音符 |

### 🧭 拍號與細分

- **每小節拍數**：1–16 任意設定（含 5、7 等奇數拍）；
- **音符細分**：四分 / 八分 / 三連音 / 十六分，視覺區會顯示口癖計數（`1` `e` `&` `a`）；
- **重音模式**：每小節重拍 / 每拍重音 / 無重音；
- **預備拍**：開始前播放 1–2 小節計數，統計自動從正式演奏開始累計。

### 🥁 複節奏訓練（特色功能）

1. 勾選 **啟用複節奏**；
2. 輸入節奏比，如 `3:2`（左手每 3 拍 3 下、右手每 2 拍 2 下的經典疊加）；
3. 可設定獨立基準速度，或留空跟隨主速度；
4. 面板會顯示循環長度（如 `6 拍 · 3000 ms`），兩個聲部以不同音高區分。

> 💡 **練習建議**：先用 `2:3` 慢速熟悉，再逐步過渡到 `3:4`、`4:5`。

### 📈 速度階梯與練習例程

在 **練習例程** 卡片中：

1. 展開 **產生速度階梯**，填寫 從/到/每級幅度/每級小節，點擊產生；
2. 也可以點擊 **新增步驟** 手動編排，每步可單獨設定速度、小節數、細分；
3. 點擊 **播放例程**，到時間自動切換到下一步，面板即時顯示 `第 2/6 步`；
4. 支援 **匯出例程**（JSON）與 **匯入例程**，方便備份和分享。

### 🔥 練習統計與打卡

- 每次演奏自動記錄小節數、時長與加權平均速度；
- 17 週熱力圖一眼看出練習規律，連續打卡天數激勵每日練習；
- 資料儲存於瀏覽器 `localStorage`，**不上傳、不同步、可隨時清除**。

### 🔗 設定分享

點擊 **複製分享連結**，目前全部設定（速度、拍號、細分、搖擺、音色、複節奏…）
會編碼進 URL 雜湊；對方開啟連結即得到完全一致的配置。

## 💡 設計思路與迭代規劃

### 設計理念

- **預調度優於計時器**：`setInterval` 受事件迴圈與分頁降頻影響，誤差可達數十毫秒。
  TempoLens 每影格只做一件事：把未來 120ms 內的點擊規劃出來並交給音訊層按絕對時間播放，
  視覺層則消費同一事件佇列，做到「所見即所聽」；
- **純函數核心 + 薄殼 UI**：所有節拍數學（`core/` 目錄）都是無副作用純函數，
  可在 Node 中直接單元測試；DOM 與音訊只做薄封裝；
- **零依賴是特性不是限制**：不鎖定任何框架版本，原始碼可讀、可稽核、可永久維護；
- **隱私優先**：沒有帳號、沒有後端、沒有遙測，練習資料完全屬於使用者。

### 技術選型原因

| 選型 | 原因 |
|---|---|
| 原生 JS + UMD | 瀏覽器全域與 Node 測試雙相容，無需打包器 |
| Web Audio 合成音色 | 零音訊素材，三種音色全部即時合成 |
| `localStorage` | 零後端實現統計與例程持久化 |
| CSS 自訂屬性 | 深淺雙主題零 JS 成本切換 |
| `node --test` | 零依賴測試執行器，CI 無需 `npm install` |

### 迭代規劃 / Roadmap

- [ ] 不規則拍號（如 3+3+2 加法節奏）與自訂重音 pattern
- [ ] 練習例程的隨機/洗牌模式
- [ ] 錄音比對（記錄演奏並與節拍對齊回放）
- [ ] PWA 支援（Service Worker 完全離線快取）
- [ ] 更多音色與音量包絡自訂
- [ ] 練習資料匯入/匯出（JSON 備份）

### 社群貢獻方向

歡迎參考 [CONTRIBUTING.md](CONTRIBUTING.md)：新增語言翻譯、補充測試案例、
實作 Roadmap 功能、改善無障礙體驗都是非常好的起點。

## 📦 打包與部署指南

### 本機打包

```bash
node scripts/build.mjs
# 產物：dist/tempolens.html（單檔案，內嵌全部樣式與腳本）
```

### 部署

TempoLens 是**純靜態應用**，任何靜態託管都可以：

| 平台 | 操作 |
|---|---|
| GitHub Pages | 推送 `src/` 目錄（或 `dist/` 單檔案）到 `gh-pages` 分支，Settings → Pages 開啟 |
| Vercel / Netlify | 拖曳 `src/` 資料夾即可，無需建置命令 |
| 任意網頁伺服器 | Nginx/Apache 指向 `src/` 目錄即可 |
| 離線散佈 | 直接寄送 `dist/tempolens.html` 單檔案 |

### 相容環境

- **瀏覽器**：Chrome / Edge / Firefox / Safari 近兩年任意現代版本（需支援 Web Audio；
  不支援時自動退化為純視覺模式）；
- **桌面端**：Windows 10+ / macOS 11+ / Linux（任意現代發行版）；
- **行動端**：iOS Safari 15+ / Android Chrome（響應式版面，支援觸控）；
- **開發工具**：Node.js ≥ 18.17（僅語法校驗、測試、打包需要）。

### CI 品質把關

每次推送與 PR 都會在 GitHub Actions 雲端執行（Ubuntu / Windows / macOS × Node 20/22 矩陣）：

1. `node scripts/check-syntax.mjs` —— 全量語法校驗；
2. `node --test test/` —— 單元測試；
3. `node scripts/build.mjs` —— 單檔案打包；
4. `node scripts/smoke.mjs` —— 靜態伺服器冒煙測試。
